# Provider projection boundary

arrangement-plan.schema.json is a conservative structural projection of canonical ArrangementPlan 0.1: references inlined, const represented as enum, required properties and additionalProperties:false retained. Numerical bounds and cross-field rules remain mandatory in local validators. The test deliberately demonstrates schema-valid but musically invalid output.

No provider model identifier or endpoint compatibility is frozen. No key/model pair is configured in the observed environment, so no live preflight ran. Phase 2D must verify the configured provider's supported schema subset with a small structured-response preflight, handle refusal/truncation/rate errors, and propose any projection amendment through the integrator. Never send raw EEG. A projection is not executable code, plan approval or audition.
