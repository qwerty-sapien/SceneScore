# Independent annotation workflow

All commands are `PYTHONPATH=.:src .venv/bin/python -m modules.muse.acquisition ...` from the installed project root. These tools create local records, not genuine participant evidence by themselves. The phase has collected **zero participant sessions**, trained zero models and measured no detection accuracy.

`cues SESSION --mode randomized_instructed --seed 7 --count 10` creates a bounded randomized intent schedule. Modes are `natural_activity`, `randomized_instructed`, `self_paced`; intervals are exploratory 5–12 protocol seconds. The schedule is a plan, not a precisely timed automatic cue presenter. Record actual occurrence later via independent review. Natural activity rotates ordinary rest, reading, watching, speech, smiles, looking, head turns, jaw activity, gentle adjustment and ordinary blinks. Self-paced input avoids teaching a cue rhythm.

`confirm SESSION CUE_ID --performed performed --confirmation-s 30` appends delayed performed/missed/uncertain self-report to `responses.jsonl`. Cue and response data are always `is_ground_truth:false`. Confirmation is delayed; do not press keys simultaneously with blinks and teach movement artifacts. Cue schedule timing, responses, audio/game feedback and detector predictions are never features or automatic truth labels.

`label SESSION --reviewer reviewer-01 --source independent_observation --evidence-ref LOCAL_REFERENCE --epoch RECORDED_SOURCE_EPOCH --onset-s 1 --final-blink-s 1.4 --end-s 1.5 --gesture-count 2 --intent deliberate --certainty verified` appends a reviewed timing annotation. Required sources are independent observation, consented local video or independent review with a local evidence reference. Times must lie inside a recorded source epoch. Gesture intent can be deliberate/natural/ambiguous; certainty is verified/uncertain/disagreement. A synthetic recording never creates real ground truth even if software-test labels say verified. Detector/cue/prediction sources are rejected. The tool cannot prove that the reviewer is truthful or that clock synchronization is valid; independent annotation and clock review remain human responsibilities.

Relabel with `--supersedes LABEL_ID`; history is append-only. Verify previous IDs exist; do not rewrite original labels silently. A future evaluator resolves supersession and disagreement before locking labels. No evaluation automatically runs in this stage. Every reviewer must distinguish actual start/end/final-blink times, intention uncertainty and labeling-source uncertainty.

Before collection, obtain participant consent, use pseudonymous participant/session IDs, fit comfortably and allow stop/rest. Suggested preparation goals remain 200–300 verified deliberate doubles and 60–120 minutes of varied natural activity across independently refitted sessions if practical, not an instruction to exhaust someone or guarantee accuracy. Include self-paced gestures and spontaneous clusters. Reserve complete refit sessions for untouched final evaluation **before** comparing/tuning any model; no adjacent-window splitting. Optional triples require separately authorized experiments. Consent for any future local webcam timing is separate; this module neither starts cameras nor sends data outside the machine.

Read docs/EVALUATION.md and the blink-evaluation skill before Phase 3A. Missing independent labels, consent, units, locked split or event matcher blocks empirical evaluation/training, while fixture tests remain available.
