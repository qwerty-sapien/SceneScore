# Frozen event evaluation

`python -m modules.muse.evaluation INPUT.json --output REPORT.json --tolerance .75` consumes complete independent labels/accepted decisions, elapsed and armed seconds. Freeze tolerance before final evaluation. The default is an uncalibrated starting assumption, not a measured optimum. Inputs use session-local seconds with explicit `session_id` and source `epoch`. Run each session separately for exposure-correct session rates; pooled reporting must sum exposure and counts, never average rates equally.

Chronological decisions match the nearest unused verified deliberate double within tolerance in the **same session and epoch**, with distance, label time and ID tie order. A decision cannot precede the independently labelled final blink. Duplicates and unmatched accepted decisions are FP. All verified deliberate doubles remain in recall, including ineligible, poor-quality and cooldown attempts. `eligible` must come from the recorded availability stream, not post-hoc model success. Uncertain/disputed labels are counted separately; rerun preregistered strict/lenient label sensitivity as separate reports. AUC/AP require the full candidate stream and both classes; tied-score AP is order invariant. Upstream candidate coverage is still a separate required analysis.

The report includes pairs, misses, ordinary/double/triple confusion, per-session counts, both false-rate denominators, final-blink decision latency and idealized all-success/zero-FP one-sided bounds. Nonzero-error intervals, onset latency, quality/refit stratification, session bootstrap and raw-stream feature extraction are not yet automated. With no eligible real data these are unresolved empirical pipeline extensions, not passing release checks. The report explicitly returns `INSUFFICIENT_SESSION_EVIDENCE`. A claimed real input returns `REAL_PROVENANCE_NOT_VERIFIED`; only a reviewed audit/card can promote a real report. Replaying the same recording never increases sample size.

No event evaluation can establish a musical listening judgment, physical AV latency or cross-person reliability.
