# Node 01 — music semantics supplement integration

Coordinator API agreement: `motion_semantics_summary(scene, states, events, *, geometry=None, config=None)` in `modules/blender/summary.py`; `music_summary(bundle_dir, config=None)` is the file adapter. Canonical records, `pair_timeline`, exporter onset semantics, contract 0.1 and the legacy compact summary are unchanged. The new module supplement is explicitly versioned `blender-music-semantics-2`.

Pass the exact frozen `manifest.json`, full `object_states.jsonl`, `interactions.jsonl` and `geometry.json`. The adapter returns sorted `events`, `suppressed`, exact numeric `config`, `config_hash` and input/config provenance hashes. Pure-function input hashes canonicalize state/event order; file-adapter hashes additionally bind exact persisted bytes. Source cadence is declared separately from the denser state intervals. The exported source hash/version and the new module source hashes in the handoff identify both derivation stages.

Each event has `id`, `source_event_id`, `source_event_ids`, `event_type`, `scene_id`, `pair`, `pair_id`, `loop_instance`, `onset_s`, `duration_s`, `driver`, `driver_reason`, `inputs`, `method`, `clock:scene`, and `epoch:scene_id`. The numeric driver is bounded to [0,1]. A null driver means the original score remains unchanged; consult the logged reason. This is supplemental mapping input, not an additional field on an `InteractionEvent`, a new canonical feature enum, or a performance approval.

- Approach uses the canonical bracket-minimum normal speed, as the taxonomy specifies. It is explicitly an offline episode descriptor (`causal_conducting_input:false`). It must not control the earlier approach prefix based on future outcome; node 04 must derive a causal common approach envelope at score times. This descriptor is never the conducting world-Z policy.
- Near miss keeps the canonical bracket `onset_s` and exposes `minimum_s` separately. Musical withholding starts at `minimum_s`. `inputs.min_gap_m` and `inputs.closeness` are backed by an independently rechecked strict positive bracket and every evaluated segment: exact sphere sweep or conservative fixed-proxy Lipschitz gap bound. Missing coverage, changing bounds, unknown proxy provenance or a tunnelling segment yields a null driver with `certified_no_tunnelling:false`.
- Separation uses the immediate outgoing evaluated interval. Contact onset/collision use the incoming/contact-containing interval, projected on the pair axis at the trigger; collision uses its exact root fraction. Release uses the interval ending at the first post-contact sample. Sustain uses its canonical duration. Missing intervals never extrapolate.
- Same-pair/same-loop sampled contact within `contact_dedupe_s` is matched one-to-one to a swept collision. Keep the swept ID/time, merge source references, and log the dropped sampled onset. The canonical input still contains both records.
- Rebound requires a triggering retained contact, area ratio >=4 by default, evaluated world mesh area provenance, negative-to-positive normal reversal, both speeds >=0.05 m/s, and observed adjacent intervals within 0.25 seconds. Smaller/larger roles use evaluated areas, not pair ordering or object-origin metadata. Output carries `trigger_event_id`, role IDs, `area_ratio`, clamped `speed_retention`, `chain_id`/`chain_index`, and required false physical disclaimers. A below-floor pre-contact speed produces no rebound event and null retention in its suppression diagnostic. No chain annotation adds events or grants a downstream density budget.

The frozen taxonomy simultaneously requires both rebound speeds above the floor and a low-pre-speed null retention control. This implementation satisfies both: the low-speed case is rejected, while its diagnostic retention remains null. It never emits an ineligible rebound just to expose a null metric.
