# Six-hour budget

| Node | Budget | Hard stop behaviour |
|---|---|---|
| 00 baseline freeze | 25 min | Ship the decision record even if incomplete; name what was not verified. |
| 01 motion semantics | 60 min | Cut asymmetric_rebound first, then collision dedupe. Keep the seven existing types. |
| 02 catalogue audition | 40 min | Keep one composition and one groove. Defer the lead-sheet defect fix to a note. |
| 03 transform vocabulary | 50 min | Cut to articulation, velocity and grace-note only. |
| 04 motion to intent | 50 min | Cut to approach, near_miss, contact_onset. Others fall back to the unmodified score. |
| 05 transition table | 45 min | Ship contract_default tier only; leave auditioned_jazz flag off. |
| 06 browser integration | 50 min | Keyboard path first. Muse mode stays visibly unavailable. |
| 07 audition and timing | 40 min | Record measurements and an honest AUDITION_PENDING rather than skipping. |
| 08 independent gate | 30 min | Always runs. A pack that skips its gate has produced nothing. |

Total 6h 30m of node work against a 6h wall clock, so roughly one node will be cut. Cut
from the bottom of each node's own list, never from the gate.

## Explicitly out of slice

Real Muse hardware. New compositions beyond the four seeds. A numeric mapping editor.
Automatic looping. Imported-plan diff UI. Safari parity. Physical acoustic latency
measurement. Learned audiovisual embeddings. Arbitrary-duration generation. General
algorithmic composition. Any of these appearing in a deliverable is scope creep, and any
of them appearing in a *claim* is a fabrication.

## Honest end states

Within six hours the reachable status is `PIPELINE_TESTED_ONLY` plus, if a human actually
listens, a recorded audition verdict. `SUPERVISED_DEMO_READY` requires evidence this
timebox cannot produce. Do not promote the label to match the effort spent.
