# 03: establish tests capable of rejecting the current result

Depends on 00. Own independent tests/reference fixtures. Do not change the generator to satisfy your expected values or edit production thresholds after a failure without a recorded justification.

1. Turn the provided analytical positive/negative cases into local regression tests. Verify their formulas independently; adapt their interface to the existing harness. Add Blender regression-scene specifications for drop/bounce, stable contact, rotated solids, fast pass-through, release handoff, tower impact and the matched miss. Tests must report object pair, frame/time, tolerance, actual value and evidence.
2. Freeze a negative reference from the actual uploaded draft. At minimum, reject its large block overlap and unsupported ending in the new realistic profile. Preserve legacy fixture/schema compatibility separately. A copied sidecar or `rigid_body` flag cannot certify a scene.
3. Separate checks into: asset integrity; geometric contact; physical motion; rendered temporal integrity; and perceptual story/appearance. Passing one class cannot imply passing the others. Include valid counterexamples: constant horizontal ballistic speed, momentum-transfer collisions with zero projectile recoil, and rotated boxes with overlapping AABBs but separated solids.
4. Specify justified scale-aware numerical tolerances and sampling/solver convergence tests. Inspect full world transforms, evaluated collision shapes and enough temporal detail for the motion. Rotated solids need orientation-aware checks; broad-phase AABBs alone are insufficient. Account for contained solids and fast crossings. Do not demand continuous guarantees when the implementation only supplies sampled evidence.
5. Require mutation tests that break one property at a time: disable a collider, keyframe through a solid, hold an unsupported body, shrink a parent, drop release velocity, add spurious near-miss contact/Foley, reuse a stale bake, and duplicate low-FPS frames into a high-FPS container. Use actual production outputs or scenes, not only hand-authored metadata. The relevant gate must fail even when filenames and metadata are plausible.
6. Keep test expected values independent of production recipe functions. Use closed-form isolated cases, geometric invariants and fresh-run cross-checks. Conservation tests must specify their system boundary and external forces; do not demand projectile-only momentum conservation against a floor or supported target.

Deliver executable small reference checks, regression-scene plans, a fixed acceptance ledger and evidence that the relevant negative baseline fails. Where Blender-dependent tests cannot run yet, mark them pending rather than substituting synthetic test success. Prompt 05 executes the complete candidate suite.
