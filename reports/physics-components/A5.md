# A5 — Mechanism component library

PASS for reusable construction and numerical connection validation. All nine
requested components have independently owned geometry routines, a common typed
specification, immutable evaluated anchors/boxes, deterministic serialization,
parameters, world bounds and explicit feasibility constraints. Blender is optional
until construction is requested.

Files are split into the core/rigid math, guide components, passive transitions,
fixed interaction targets, structures, connection/route validation, serialized
example, registry/CLI and Blender adapter. A separate bounded smoke runner and
host/Blender tests complete the library. See the exact [file manifest](task-files.json)
and [usage/limitations](../../docs/MECHANISM_COMPONENTS.md).

All colliders are fixed OBBs and directly consumable by the existing analytic
sphere solver. A one-tick fixture checks that interface with a supported sphere;
it does not certify any route. The library never uses a beauty mesh as collision
geometry. Separate visual copies may have bounded bevels and external materials.

Connections report strict anchor distance, direction mismatch, required/available
radius clearance, height/entry-energy requirements, static penetration depths,
joint-region bounds and minimum sphere seam gap. Invalid routes expose these
numerical reports. Branches, cycles, missing components, invalid terminal ports,
unconnected travel components, inconsistent radii, nonadjacent solid overlap and
the 128-collider backend limit are enforced.

The serialized example assembles five components from an elevated ramp through a
curve and a descending depth channel to a lower catcher. Sphere-center extents
are approximately **4.328 × 4.342 × 1.513 m**, with a measured noncoplanarity of
**0.108 m**. It remains a modest spatial study rather than a visual-quality claim.
The descending transition changes direction by **8.59°**, below its declared 10°
limit. Static weld limits are explicitly 0.06 m at the arc entry and 0.08 m at the
descending transition; actual maxima are about 0.0392 and 0.0730 m. Every sphere
seam gap remains nonnegative within arithmetic precision. Default weld permission
remains zero. The rejected original descending join is retained in
[descending-route-check.json](descending-route-check.json); no physical acceptance
threshold was relaxed.

`assemble_resolved()` revalidates A4 output and binds component IDs to declared
fixed collision actors, sphere radius, start/terminal supports and exact world
anchor positions. It returns collider-to-actor mapping and complete planning
constraints, including reference lessons and still-unmeasured event criteria.
Drop trajectories, deflector material response and catch retention remain solver
work. SupportFrame and ClearancePost cannot be used as unsupported travel floors.

Validation: **46 host component tests** pass within the 166-test final authoring
run. The [CLI receipt](components-cli.json) records successful serialized assembly.
The final [Blender receipt](blender-smoke-final.json) records Blender 5.2.1 LTS,
120-second cap, two threads, PID/PGID 67693, exit 0 and confirmed process-group
absence. The [smoke report](../../artifacts/blender/component-library-a5-final-20260913/smoke.json)
checks 9 instances/100 generated objects, passive BOX versus nonphysical visual
objects, duplicate-name rejection, preservation of factory objects, exact source
hashes and world corners (maximum error 8.92e-7 m). The editable `.blend` is in the
same directory. Runtime was approximately 1.49 seconds; no media was rendered.
